# Adaptive Convexity Framework (ACF)

*Created by Dale Edward Powell*  
February 2026

A macro-aligned portfolio architecture and decision system designed to structure asymmetric exposure across regimes. It integrates thesis modeling, the CIS (Convexity Integrity Score), tripwire logic, and disciplined execution into a unified portfolio operating model.

> An executable philosophy for asymmetric compounding during instability.  
> A holistic, tax-optimized portfolio operating system for regime shifts.

## Framework Structure

The framework is organized as a six-part document, with a seventh part as an introductory deck for the ACF Dashboard tool.  
Each section builds on the prior, moving from philosophy → architecture → implementation → governance.
